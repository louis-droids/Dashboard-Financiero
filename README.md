# Dashboard Financiero

Proyecto de análisis financiero desarrollado para practicar desarrollo de software y automatización aplicada a finanzas.

## Funcionalidades actuales

- Cálculo de utilidad a partir de ventas, costos y gastos.
- Cálculo de margen de utilidad.
- Uso de funciones reutilizables en TypeScript.

## Tecnologías utilizadas

- TypeScript
- Git
- GitHub

## Próximos pasos

El proyecto incorporará progresivamente:

- Frontend con React
- Backend con Node.js
- Integración mediante APIs
- Base de datos SQL
- KPIs financieros y visualizaciones

## Objetivo

Este proyecto busca combinar mi experiencia en finanzas y análisis financiero con el desarrollo de software, automatización y análisis de datos.
